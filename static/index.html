API 速览

所有接口均返回 JSON，默认支持跨域访问，可直接被前端或脚本调用。

  • GET /api/landmarks?server=zth

    获取指定数据源的全部地标，可用 name 参数模糊查询。

  • GET /api/landmarks/<id>

    根据地标 ID 返回完整信息，需同时传入 server。

  • GET /api/railways?server=zth

    返回指定服务器的铁路网站点，支持 name 关键词过滤线路或站名。

  • GET /api/wiki_search?query=...

    聚合 RIA Wiki 搜索结果，返回标题、链接与摘要。
